# CCTV IPv4 APTV 测试订阅

这是供 APTV 手动测试的 CCTV IPv4 直播候选合集，测速网络为河北承德电信直连。当前仓库内的订阅是 **2026-10-11 的历史检测快照**：56 条唯一线路，覆盖 CCTV-1 至 CCTV-17 与 CCTV-5+ 中的 16/18 个频道。CCTV-5、CCTV-10 暂缺；每个频道不足六路时如实留缺，不用失败地址补数。

这些 URL 中有短时签名，可能已经失效。该快照只表示它们在当次承德电信 IPv4 检测中的结果，不承诺今天仍可播放、长期稳定或自动切备。APTV 客户端的画面、声音、同名合并、播放中切备和晚高峰表现尚待实际测试。

## APTV 订阅地址

把地址粘贴到 APTV 的“订阅”中。聚合版和 IPv4 专用版目前内容相同，均不包含 IPv6 地址。

| 版本 | 地址 | 内容 |
| --- | --- | --- |
| **整合（推荐）** | `https://raw.githubusercontent.com/279458179/cctv-live/main/subscriptions/cctv.m3u` | 承德电信 IPv4 测试快照，56 条，16/18 频道 |
| IPv4 | `https://raw.githubusercontent.com/279458179/cctv-live/main/subscriptions/cctv-ipv4.m3u` | 与整合版相同，仅 IPv4 |

仓库不提供 IPv6 订阅。若 raw 域名访问较慢，可将地址前缀换为 `https://ghproxy.net/https://raw.githubusercontent.com/`，后面的仓库路径保持不变。

## 导入和覆盖

1. 在 APTV 打开“设置 → 订阅 → +”。
2. 输入名称并粘贴上方任一订阅地址。
3. 保存后检查频道显示、画面和声音。CCTV-5、CCTV-10 当前没有线路。

[完整导入说明](APTV-导入说明.md)列出各频道线路数和建议测试项；[覆盖摘要](docs/testing/cctv-ipv4-coverage-2026-10-11.md)记录该快照的实测边界。

## 更新方式

仓库当前不运行定时云端测速或自动重建。更新订阅前，应在目标运营商直连网络重新检查 IPv4 HLS 链路、连续播放和解码质量，再把有证据的结果写入订阅；上游清单中出现地址不代表地址健康。

本仓库整理公开直播候选，不存储或转发视频内容。请遵守平台条款与内容权利要求。
